# Brief completion

The later requests supersede the original panda/lion/mantis list, no-3D constraint and discovery-first entrance. The current brief uses the three Australian species, the supplied 3D illustrations and a global country-photo entrance.

## Implemented

- Cloned Kylektt/animalpedia; updated the application and README.
- Central Animalia title, country photography, flags, scroll-driven entrance and searchable 250-country/territory index. Only Australia is enabled.
- South Australia collection with three scroll-linked species chapters and interactive released GLBs.
- Native habitat video, playback controls, failure/retry states, credited media and photographic fallback when footage is unavailable.
- Three sourced, image-relative anatomy points per species. Anatomy stops video; returning retains the chosen clip and starts paused and muted.
- Configured video segments bound the seek range and stop at their end. Clip switching retains mute preference within Habitat.
- Desktop/mobile, keyboard, reduced-motion and rendering checks; source commits and public GitHub Pages deployment.

## Media still needed

- Reusable, correctly identified spinifex hopping mouse video. A fresh Commons and web search did not establish a directly hostable licensed clip; the photographic study remains explicitly labelled.
- Wild red-kangaroo habitat footage. The current 1080p film is explicitly a captive San Diego Zoo observation.
- Additional verified behaviour clips or reviewed timestamps. The selector supports multiple clips, but no unsupported behaviours or arbitrary documentary segments are published.

All countries are selectable in the directory only as availability permits. Country-specific collections and photographs for every directory entry are not complete: twelve countries have entrance photography, while all 250 entries have flags.

The original dark halo was superseded by the later white photographic reference and unframed model stage. No decorative halo or unrequested original species has been added back.
